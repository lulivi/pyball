# Migrate from Poetry to uv

**Date:** 2026-04-18
**Status:** Approved

## Goal

Replace Poetry with uv as the package manager, using `uv_build` as the build backend with
VCS-based dynamic versioning from git tags.

## Build System (`pyproject.toml`)

Replace `poetry-core` + `poetry-dynamic-versioning` with `uv_build`:

```toml
[build-system]
requires = ["uv_build"]
build-backend = "uv_build"

[tool.uv.build-backend]
version-source = "vcs"
```

Replace `[tool.poetry]` + `[tool.poetry.dependencies]` with PEP 621 `[project]`:

```toml
[project]
name = "pyball"
dynamic = ["version"]
description = "Bot to play them all"
license = { text = "MIT" }
authors = [{ name = "Luis Liñán", email = "luislivilla@gmail.com" }]
readme = "README.md"
requires-python = ">=3.11,<4.0"
dependencies = [
    "python-telegram-bot>=22,<23",
    "pydantic>=2.0",
    "fastapi>=0.110",
    "uvicorn[standard]>=0.29",
    "jinja2>=3.1",
    "playwright>=1.44",
]

[project.scripts]
pyball = "pyball.__main__:main"
```

Replace `[tool.poetry.group.dev.dependencies]` with PEP 735 `[dependency-groups]`:

```toml
[dependency-groups]
dev = [
    "black==22.*",
    "isort==5.*",
    "mypy",
    "pycodestyle",
    "pydocstyle",
    "pylint",
    "coverage",
    "pytest",
    "pytest-asyncio",
    "pytest-cov",
    "pytest-emoji",
    "pytest-timeout",
    "faker==18.*",
    "freezegun",
    "ddt>=1.7.1,<2",
]
```

`poetry.lock` is deleted; `uv.lock` is generated by running `uv sync`.

## nox (`noxfile.py`)

Switch venv backend to uv:

```python
nox.options.default_venv_backend = "uv"
```

Replace `poetry install --only dev` with `uv sync --only-group dev` in all three sessions
(`lint`, `test`, `format`). This is the PEP 735 equivalent: installs only the `dev`
dependency group, without the main package runtime deps (same behavior as `--only dev` in
Poetry):

```python
session.run("uv", "sync", "--only-group", "dev", external=True)
```

## Docker build script (`scripts/docker_build.py`)

Replace two Poetry calls:

| Before | After |
|---|---|
| `run("poetry", "build", "-f", "wheel")` | `run("uv", "build", "--wheel")` |
| `run("poetry", "version", "--short")` | `run("uv", "version", "--short")` |

## Files Changed

| File | Change |
|---|---|
| `pyproject.toml` | Full rewrite: build system, project metadata, dependency groups |
| `poetry.lock` | Deleted |
| `uv.lock` | Generated (`uv sync`) |
| `noxfile.py` | venv backend + install command in 3 sessions |
| `scripts/docker_build.py` | Replace 2 Poetry calls with uv equivalents |

## Out of Scope

- `docker/Dockerfile` — no changes needed (installs from `.whl`, agnostic to build tool)
- `Makefile` — no changes needed (delegates to nox)
- CI workflows — none exist currently
